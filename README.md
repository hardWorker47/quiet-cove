# Quiet Cove

A calm fishing and sailing game: a small boat, a quiet sea and 399 real fish species.

**Play in the browser:** https://hardworker47.github.io/quiet-cove/

**Android:** https://play.google.com/store/apps/details?id=com.korolev.quietbay

This repository holds the built web version only (version 1.17.1). The first load downloads about 140 MB.

Controls on a computer: arrow keys or WASD to move, mouse for everything else, Esc for the menu.
On a phone the game shows a touch joystick.
